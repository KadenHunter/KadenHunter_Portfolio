Projects

01

Database Project

I designed and implemented a relational database for a business scenario, from initial planning through to a working SQL solution. This included producing an ER diagram and a third-normal-form relational schema, then creating, populating, and testing the database using SQL. My video walkthrough demonstrates the table relationships, keys, constraints, and SQL queries used to support key business processes. This project strengthened my skills in database design, SQL development, and data handling, and achieved an overall mark of 96%.

02

Still & Moving Images

I developed a promotional design campaign for a Bentley Continental GT3 racing team, centred on the United Nations Sustainable Development Goal 14: Life Below Water. The project included an A0 event poster, a custom car livery, a 360-degree vehicle rotation, and a storyboard-led 45-second advertisement set at Spa-Francorchamps.

I used Adobe Illustrator and Photoshop to create the poster and livery, before using Adobe Premiere Pro and Adobe Audition to edit the advertisement and produce its sound design. To create footage for the final video, I drove the Spa-Francorchamps circuit in a racing simulator and captured clips for use in the advert. The final livery was produced as a layered Photoshop PSD file, which is too large to host here, but is showcased in the car-rotation video.

03

Human Computer Interaction Project

This UX/UI project explored how design decisions affect usability, accessibility, and the overall user experience. For the individual presentation, I critically compared two websites as examples of good and poor UX, using HCI principles and research to support my evaluation.

As part of a group report, I helped develop a structured framework based on usability heuristics, accessibility, colour, and semiotics. I then applied this framework to evaluate a website and produce practical recommendations for improvement. The project strengthened my skills in user-centred design, critical analysis, research, and communicating design decisions.

04

The Daily Cup

As part of a group, I developed The Daily Cup, a contemporary website for a café brand. The project focused on creating a clear and accessible user experience through structured HTML, responsive CSS, and JavaScript interactivity.

The website includes a contact form with client-side validation and interactive features designed to improve usability. This project strengthened my experience of working collaboratively with version control, applying UX principles, and building a complete front-end website from planning through to implementation.
